# Needle in the Haystack

A small, original browser-based hidden-object game inspired by the general needle-in-a-haystack concept.

## Run locally

Open `index.html` in a browser.

## Deploy to Render

1. In Render, choose **New +** → **Blueprint**.
2. Connect this repository.
3. Render reads `render.yaml` and creates the static web service.
4. When the deploy finishes, open the generated `.onrender.com` URL.

The game is a static site: no server process, build step, or environment variables are required.
